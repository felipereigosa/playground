# The radio's music

All five tracks are by Kevin MacLeod (incompetech.com), licensed under
Creative Commons: By Attribution 4.0, https://creativecommons.org/licenses/by/4.0/

| Dial | File | Title |
| --- | --- | --- |
| FM 88 | `88 lobby-time.mp3` | Lobby Time |
| FM 96 | `96 local-forecast-elevator.mp3` | Local Forecast - Elevator |
| FM 102 | `102 hep-cats.mp3` | Hep Cats |
| FM 108 | `108 gymnopedie-no-1.mp3` | Gymnopedie No. 1 (Erik Satie) |
| AM 600 | `600 maple-leaf-rag.mp3` | Maple Leaf Rag (Scott Joplin) |

Changes: each was mixed down to mono, evened in loudness and re-encoded at
96 kbit/s from the mp3 at
`https://incompetech.com/music/royalty-free/mp3-royaltyfree/<Title>.mp3`.

Music of your own goes in `assets/radio/private/`, which git ignores. A file
name that starts with a free number of the dial (90, 500, 900) puts it there.
